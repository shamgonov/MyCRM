Документ-ориентир. Актуален вместо `SPEC.md` (тот — застывший мастер-промпт, расходится с кодом).
База: `HEAD = f388ef4` (main). Готовое: Этапы 0–11, 13 модулей, `SMOKE: pass=666 fail=0`.

## 0. Правила для всех этапов

- Vanilla JS ES2017+, без сборщика, без `?.` и `??`, без внешних библиотек.
- Глобальные `function` / `var` / `const`; для `const` обязателен `window.*`-экспорт.
- Экраны — в `S` (`app/core.js:154`) через ленивые `typeof fn === 'function'` обёртки.
- События — делегирование `document.addEventListener` + `data-*`; смена `<select>` — на `change`.
- Модалки — `showModal()` / `closeModal()` + контекст в `window.__*`.
- Таблицы — на CSS-grid (`arow` / `rrow`), не `<td>` вне `<table>`.
- Инлайн-скриптов (`onclick`) — нет. `styles/theme.css` не трогать. Firebase/PDF/деплой — нет.
- Сохранение — глобальный `save()` из `db.js` (не `DB.save()`).
- Каждый этап: новый модуль в `app/` + `<script>` в `index.html` + смоук в `tools/smoke/` + `node tools/check-modules.js`.
- Проверка этапа: `node tools/check-modules.js && node tools/smoke/run.js && node --check app/<новый>.js`.
- Если якорь для правки не найден — СТОП, спросить, не выдумывать.

## Этап 12 — Деньги заявки (остаток к оплате)

**Цель:** сумма / оплачено / остаток + напоминалка об остатке при завершении.

**Модель**
- `o.payments = [{ id, sum, date:'YYYY-MM-DD', method:'cash'|'card'|'transfer', by, note }]`
- `o.moneyReminderAt` — timestamp напоминания об остатке.

**Функции (`app/orders.js`)**
- `orderRevenue(o)` → `calculateOrderTotal(o)`
- `orderPaid(o)` → сумма `payments` (перенести туда `paidSum` из `ui-docs.js`, оставить алиас)
- `orderBalance(o)` → `orderRevenue(o) - orderPaid(o)`

**UI:** новый модуль `app/ui-money.js` → `renderMoneyTab(o)`; вкладка `money` в список вкладок (`app/ui-orders.js:100`), обработчик `data-tab` уже универсальный (`ui-orders.js:220`).
- Итоги: к оплате / оплачено / остаток (`money()` из `db.js`).
- «＋ Платёж» → модалка (сумма, способ, дата, комментарий) → `push` в `o.payments` + запись в `o.history`.
- Удаление/правка платежа — только `can('settings_edit')` или автор.

**Завершение заявки:** при переходе в `completed` (обработчик `data-status-select`, `ui-orders.js:263`) и `orderBalance(o) > 0` — модалка «Остаток к оплате N ₽» + чекбокс «Напомнить об оплате» → `o.moneyReminderAt`.

**Права:** добавить `payments_add` в `PERMS_CATALOG` (`app/auth.js:29`) — owner/manager/worker.

**Смоук:** `tools/smoke/_money_smoke.js` — баланс, добавление платежа, запрет при отсутствии права, срабатывание напоминания.
