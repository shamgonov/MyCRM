# Смоук-тесты CRM2

- Раннер: `node tools/smoke/run.js` — запускает все `smoke-*.js` из этой папки.
- Один файл = один модуль/этап: `smoke-auth.js`, `smoke-sync.js`, `smoke-gates.js`, …
- В контексте доступны `assert(cond, msg)`, `assert.eq(a, b, msg)`,
  общий `window` (модули делят глобальные объекты, как в браузере).
- Модуль под тестом читается через `fs` и исполняется в том же контексте
  (см. пример в файлах последующих этапов) — без сборщика и без браузера.
- Гейт перед коммитом: `node tools/check-modules.js && node tools/smoke/run.js`.
